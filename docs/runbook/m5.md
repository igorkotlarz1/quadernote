# M5 – codzienna powtórka (runbook)

Cel M5: codziennie aplikacja sama wybiera, co powtórzyć. Bez API i bez kosztów, działa też w trybie samolotowym.
Każdy krok ma „oczekiwane:”. Jeśli wynik jest inny, zatrzymaj się i wklej mi go (albo zrzut ekranu).

Potrzebne: M3 działa (aplikacja zainstalowana na telefonie, adres `https://….ts.net`).

## 1. Aktualizacja na Optiplexie

```bash
cd ~/quaderno && git pull && docker compose up -d --build
curl -s localhost:8000/api/reviews; echo
```

Oczekiwane: `{"reviews":[],"last":0,"more":false}`. Migracja `0004` założyła tabelę `reviews` (dziennik odpowiedzi).

## 2. Telefon: pierwsza powtórka (dzień 1)

1. Otwórz Quadernote z ikony (z siecią). Jeśli widzisz starą wersję, zamknij i otwórz drugi raz.
2. Na górze, pod datą, ramka **Powtórka**. Oczekiwane: „Na dziś: 0 kart do powtórki i 10 nowych”
   (mniej, jeśli masz mniej słówek z tłumaczeniem; słówka bez tłumaczenia nie dają kart).
3. **Zacznij powtórkę.** Trzy rodzaje kart:
   - **IT → PL**: włoskie słowo, **Pokaż odpowiedź**, oceń się: **Znowu · Trudne · Dobrze · Łatwe**;
   - **PL → IT**: wpisz po włosku, **Sprawdź**. Bez akcentu (`perche`) = „Prawie: akcent”;
   - **czasownik**: „parlare, noi → ?”, wpisz formę.
   Karta z „Znowu” wraca jeszcze dziś, na końcu.
4. Oczekiwane po ostatniej karcie: „Koniec na dziś” i data następnej powtórki.
5. Na serwerze: `curl -s localhost:8000/api/reviews | head -c 300; echo`. Oczekiwane: Twoje odpowiedzi z `"seq"`.

## 3. Bramka: następne dni

1. **Dzień 2:** otwórz aplikację. Oczekiwane: znowu nowe karty, a wczorajsze „Dobrze” jeszcze nie wracają.
2. **Za kilka dni** (zwykle 3–6 po „Dobrze”): oczekiwane „Na dziś: N kart do powtórki”. Te karty wybrała aplikacja,
   nikt jej ich nie podał.
3. Jednego dnia zrób powtórkę w **trybie samolotowym**. Oczekiwane: działa tak samo, a w **Ustawieniach powtórek**
   widać „… czeka na wysłanie”. Po wyłączeniu trybu samolotowego ten dopisek znika w ciągu minuty.
4. Laptop: otwórz `https://….ts.net`. Oczekiwane: ta sama liczba kart na dziś co na telefonie.

Bramka zaliczona, gdy krok 2 się zgadza. Automatycznie to samo (z przestawionym zegarem przeglądarki: dzień 1,
dzień 2, dzień 11 offline, drugi komputer) sprawdza `web/e2e/gate_m5.spec.ts`.

## Ustawienia

**Powtórka → Ustawienia powtórek**: ile nowych kart dziennie (domyślnie 10) i ile pamiętać (90% zalecane;
95% = więcej powtórek, 85% = mniej). Ustawienia są osobne na każdym urządzeniu.

## Gdy coś nie działa

- **Brak ramki „Powtórka”**: stara wersja aplikacji. Zamknij i otwórz drugi raz.
- **„… czeka na wysłanie” nie znika**: sprawdź Tailscale i `docker compose logs api --tail 50`, wklej mi wynik.
- **Słowo nie ma karty**: karty powstają tylko ze słówek z tłumaczeniem. To samo słowo w dwóch lekcjach to jedna karta.
- **Czasownik nie ma karty**: czasowniki „do sprawdzenia” czekają, aż Claude albo Ty potwierdzicie formy.
